# Transgema Industrial — "Strata" design

Full bilingual (ES/EN) website built in the Strata direction: the four divisions
are presented as geological layers — from surface environmental testing down to
the technology bedrock — a nod to the company's soil/earth work.

## Files
- `index.html` — complete site (all CSS inline, no build step)
- `CNAME` — custom domain (transgema.com)

## Sections
Hero · Strata divisions (4, with service chips) · About · Sustainability
(circular-economy ring) · Contact form · Footer.

## Features
- Bilingual: EN/ES toggle in the nav, switches all text instantly; choice
  remembered between visits. Spanish is the professional default content.
- Type: Fraunces (serif display) + Inter (body).
- Palette: brand green #2ECC71 / deeper #1B7D45 on a warm cream base, with
  earth-tone strata layers (green → stone → clay → sand).
- Responsive to mobile; reduced-motion respected.
